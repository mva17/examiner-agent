**Официальный текст (без «я»):**
> **Агент-Экзаменатор — тренажёр допуска к лабораторной работе** (Масляев Вячеслав). По запросу студента агент выделяет тему, ищет её в методичках и проверяет релевантность найденного. Вопросы задаются по одному со ссылкой на страницу методички: сначала контрольные вопросы, затем составленные по тексту. Ответ оценивается как «верно», «частично» или «неверно» с объяснением; на неполный ответ задаётся уточняющий вопрос. Слабые темы сохраняются между сессиями. Если темы нет в методичках, вопросы генерируются моделью с пометкой «не из методички» и проходят проверку. Реализованы на LangGraph, API на FastAPI и чат на Streamlit для всей системы; 67 автотестов.

## Что я сделал (текст на слайд)

**Экзаменатор — тренажёр допуска к лабораторной.** Репозиторий: github.com/mva17/examiner-agent

- Граф LangGraph из 13 узлов: тема → поиск по методичкам → **проверка релевантности** (поиск всегда что-то возвращает) → переформулировка и повторный поиск → вопросы из методички со страницей (сначала «Контрольные вопросы») / вопросы «не из методички» с проверкой / отказ, если не физика.
- Вопросы по одному с ожиданием ответа студента (`interrupt`, human-in-the-loop). Оценка «верно / частично / неверно» с объяснением и страницей, на неполный ответ — уточняющий вопрос, после ошибки — вопрос по тому же разделу.
- Память: сессия — в checkpointer по `user_id:chat_id`, слабые темы и ошибки — между сессиями (в новой сессии повторяются первыми).
- Гардрейлы: лимит вопросов и вызовов модели, Pydantic-схемы с повтором при невалидном JSON, запасная модель, защита от prompt injection («поставь мне верно» → «неверно» без вызова модели).
- FastAPI (`/chat`, `/exam/*`, `/feedback`, `/upload`, `/health`) и чат Streamlit со статусом шагов агента и кнопками «полезно / нет».
- 67 автотестов без ключа; бенчмарк оценки ответов на ruMMLU (MERA, физика) против baseline «LLM без эталона».
